Maintenance du Système
Exporter les données

Générez un fichier de sauvegarde (.sql) contenant l'intégralité des données de l'application (Missions, Clients, Utilisateurs, Configuration, etc.).

Il est recommandé d'effectuer une sauvegarde régulière de vos données.
Importer / Restaurer

Restaurez la base de données à partir d'un fichier de sauvegarde précédemment exporté.

Attention : Cette opération remplacera toutes les données actuelles par celles contenues dans le fichier.
Remise à zéro complète

Supprimez l'intégralité des données de l'application (Missions, Clients, Historiques, Déploiements, etc.).

Action irréversible : Cette opération est définitive. Seuls les comptes utilisateurs seront conservés pour vous permettre de vous reconnecter.
Tables incluses dans la sauvegarde
Utilisateurs (CNUSE) Clients (CNCLI) Intervenants (CNINT) Missions (CNMIS) Notifications (CNNOT) Audit (CNAUD) Versions (CNAPPVERSION) Fonctionnalités (CNFEATURE) Déploiements (CNDEPLOYMENT) Configuration (CNCFG)
